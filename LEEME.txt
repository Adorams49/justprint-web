JUST PRINT - PAGINA WEB
=======================

DONDE VIVE AHORA (desde 22-sep-2026)
  El sitio ya NO esta en GoDaddy. Vive en GitHub, en el repositorio publico
    https://github.com/Adorams49/justprint-web
  y se publica solo con GitHub Pages cada vez que se sube un cambio a la
  rama "main" (lo hace el flujo .github/workflows/deploy.yml).
  El HTTPS (candado) tambien es automatico: lo emite y renueva GitHub, no
  hay certificados que vencer ni tocar nunca mas.
  GoDaddy solo sigue siendo donde esta registrado el dominio; el DNS de
  justprinthn.com apunta a los servidores de GitHub Pages.

  IMPORTANTE: este repo es PUBLICO y separado del repo de la app de
  operaciones (Just-Print). build.py, data/, los .bat y este LEEME nunca
  quedan visibles en la pagina publicada (el flujo solo publica index.html,
  404.html, assets/, servicios/, sitemap.xml y robots.txt).

VER LA PAGINA EN TU PC (antes de subir cambios)
  Doble clic en  ver-pagina.bat   (abre http://localhost:8080)

COMO ACTUALIZAR LA PAGINA
  Lo normal: decirle a Ari (o pedirselo a Claude) que necesitas cambiar, y
  el edita, corre build.py y sube el cambio. Se ve reflejado en
  justprinthn.com en menos de un minuto.

  Si alguna vez lo haces tu a mano:
    1. Edita config.js, services.json, index.html, etc.
    2. Doble clic en construir.bat (regenera las paginas de servicio).
    3. git add -A && git commit -m "..." && git push

DONDE EDITAR (todo esta separado para que sea facil)
  assets/js/config.js     Telefono, correo, horario, direccion, mapa, redes
                          sociales y las preguntas frecuentes.
  data/services.json      Los 12 servicios (textos, listas, colores).
                          Despues de editarlo, doble clic en  construir.bat
                          para regenerar las paginas de cada servicio.
  assets/img/             Fotos y logos.

GALERIA "NUESTRO TRABAJO", CLIENTES Y TESTIMONIOS  (todo en config.js)
  GALLERY        Las fotos que se deslizan de lado. Para agregar tus propias
                 fotos: subelas a assets/img/ y agrega una linea.
  CLIENTS        Logos o nombres de clientes. Vacio = la seccion no aparece.
  TESTIMONIALS   Testimonios. Vacio = la seccion no aparece.

CONTACTO Y CATALOGO
  No hay formulario ni descarga de PDF en la pagina: todo redirige a
  llamar al telefono o escribir al correo (para no generarle carga extra
  al negocio). Si algun dia quieren volver a ofrecer descarga o formulario,
  se puede reactivar.

REDES SOCIALES
  Estan como iconos sin enlace. Pega el enlace en config.js (SOCIAL) y el
  icono se vuelve un boton real.

DOMINIO / SEO
  build.py tiene DOMAIN = https://justprinthn.com (para sitemap y Google).
